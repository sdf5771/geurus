Speech Bubble · 정원 패널

그루가 지금 무엇을 하는지 알리는 픽셀아트 말풍선과, 그루들이 모여 있는 정원 패널이에요. 말풍선 테두리는 라운드가 아니라 픽셀 계단으로 깎았고, 패널은 창 테두리 없이 투명 배경 위에 뜹니다. 포즈·모션은 앞 문서의 POSE·MOTION을 그대로 씁니다.
산출물 ③ — Speech bubble
말풍선 · 상태 3종
배경 --c-bg-elevated · 테두리 --c-border-strong. 좌측 바로 상태를 구분해요 — 기본은 바 없음, 경고 --c-danger, 성공 --c-success. 한글은 Noto Sans KR, 숫자·툴명은 IBM Plex Mono로 섞습니다.
Tail direction
꼬리 방향 4종
그루가 패널 어디에 있느냐에 따라 꼬리를 고릅니다. 그루가 아래에 있으면 down, 위에 있으면 up, 좌우 공간이 없으면 left/right. 꼬리는 3px 계단이라 픽셀 결이 유지돼요.
Width rules
폭 규칙
min 84px최소 폭 — 완료 · 2m처럼 짧은 카피도 꼬리가 붙을 자리를 확보해요.
max 208px최대 폭 — 패널 폭 360px의 약 58%. 넘치면 말줄임. 두 줄로 흐르지 않게 한 줄 고정.
padding가로 8px · 세로 5px. 테두리 2px를 포함해 픽셀 정렬이 깨지지 않는 값.
overflow툴명이 길면 툴명을 우선 보존하고 뒤 문장을 줄여요 — Bash 실행 중 · 40s → Bash… · 40s가 아니라 Bash 실행… · 40s.
// 말풍선 — 픽셀 계단 테두리 · 꼬리 4방향 const BUBBLE = { minW: 84, maxW: 208, padX: 8, padY: 5, border: 2, corner: 2, // 계단 깊이(px) — 라운드 대신 tail: { size: 3, dirs: ['down','up','left','right'] }, kind: { base: { bar: null }, warning: { bar: '--c-danger' }, // 승인 대기 · 인증 필요 success: { bar: '--c-success' }, // 완료 }, };
산출물 ④ — Garden panel
정원 패널 · 배경 2안
권장 360 × 240(내용에 따라 세로 가변). 프로젝트 하나가 화단 한 줄이고 그 흙 위에 그루가 서요. 창 테두리가 없으니 상단 그립 바가 유일한 드래그 손잡이예요 — 체커보드는 투명 영역입니다.
Rules
배치 · 상한 · 우선순위
한 화단에 최대 5마리까지 세우고 넘으면 +N으로 접어요. 화단은 최대 3개까지 보이고, 그 아래는 스크롤 대신 접힌 프로젝트 줄로 요약합니다.
// 정원 패널 배치 규칙 const GARDEN = { size: { w: 360, minH: 240 }, // 세로는 화단 수에 따라 가변 bedsVisible: 3, // 초과 프로젝트는 접힌 줄로 slotsPerBed: 5, // 초과 그루는 +N 배지 // 큰·앞에 둘 순서 — 위가 우선 priority: ['blocked','crashed','done','working','idle'], scaleByPriority: { blocked: 3, crashed: 3, done: 2, working: 2, idle: 2 }, grip: { h: 26, drag: true }, // 창 테두리 없음 → 유일한 손잡이 bg: 'solid', // 'solid' | 'clear' };
다음 단계
3단(⑤ 타입 구분 · ⑥ 빈 상태 · ⑦ 트레이)으로 마감하면 돼요. ⑤는 색을 못 쓰는 제약이 있으니 잎 변주 · 발밑 배지 · 배율 차등 세 방향을 비교안으로 만들 예정입니다.
